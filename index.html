잠금 화면의 순간을
다시 움직이세요.

직접 고른 영상은 잠금 화면용 Live Photo로, 사진 속 순간들은 부드럽게 이어지는 MP4·GIF로 만드세요. 선택한 사진·영상은 iPhone 안에서 처리됩니다.

이메일로 문의하기

잠금 화면 모션 만들기

  1. 01iPhone 맞춤 설정

    첫 실행 안내에 따라 이 iPhone 맞춤용 Live Photo를 한 번 촬영합니다.

  2. 02영상 선택

    사진 앱에서 권리가 있는 영상을 직접 고릅니다.

  3. 03구간 선택

    기본 2초, 최대 3초의 움직임과 대표 사진을 정합니다.

  4. 04저장

    Live Photo를 만들고 사진 앱에서 새 잠금 화면으로 설정합니다.

사진 여러 장으로 영상 만들기

  1. 홈에서 Video Studio → 사진 페이드를 엽니다. 카메라 촬영이나 iPhone 맞춤 설정은 필요하지 않습니다.
  2. 사진 2–30장을 직접 고르고 순서를 확인합니다.
  3. 미리보기를 재생하고 맞춤에서 대상이나 사진 위치·크기를 조절합니다. 비교가 끝나고 필요한 확인을 마치면 저장할 수 있습니다.
  4. 색감·꾸미기·속도를 조절한 뒤 저장 옵션 설정을 누르고 MP4 또는 GIF를 고릅니다. 두 형식 모두 무음이며 Live Photo와는 별개입니다.
  5. 사진 앱에 저장을 누릅니다. 사진 추가 권한을 요청하면 허용한 뒤 사진 앱에서 결과를 엽니다. 편집을 닫아도 원본 사진은 지워지지 않습니다.

홈의 추천 영상이 움직이지 않아요

  • 홈에서는 이미 다운로드한 추천 영상만 무음으로 재생합니다. 아직 받지 않은 추천은 정지 미리보기로 보입니다.
  • 동작 줄이기가 켜져 있거나 앱이 비활성 상태이거나 Video Studio를 열면 재생을 멈춥니다. 설정에서 다운로드를 지웠다면 다시 받아 주세요.
  • 추천을 불러오지 못해도 내 사진·영상으로 편집할 수 있습니다. 오프라인에서는 iCloud에만 있는 원본을 새로 내려받을 수 없으므로 기기에 저장된 항목을 사용해 주세요.

모션을 사용할 수 없나요?

  • WakeMotion 설정에서 잠금 화면 호환성을 한 단계 높여 다시 만들어 보세요.
  • 빠른 화면 전환이나 큰 카메라 이동을 피하고 더 안정적인 구간을 골라 보세요.
  • 호환성 3도 모든 영상과 iOS 버전에서 동작을 보장하지는 않습니다.

문제가 계속되면 알려주세요.
