1. 서비스 개요

WakeMotion은 사용자가 직접 선택한 동영상의 일부를 iPhone 잠금 화면용 Live Photo로 변환하고 일반 동영상을 편집·저장하는 온디바이스 앱입니다. 계정, WakeMotion 서버 변환, SNS 다운로드 또는 공개 게시 기능은 제공하지 않습니다.

무료 버전은 Google Mobile Ads를 이용한 배너 광고와 사용자가 저장 시 선택하는 보상형 광고를 제공하며, Google User Messaging Platform을 이용해 적용 지역의 개인정보 선택을 표시할 수 있습니다.

2. 앱이 기기 안에서 처리하는 정보

  • Apple 시스템 사진 선택기에서 사용자가 명시적으로 고른 동영상
  • 선택 구간, 대표 사진 시점, PIP·overlay 등 편집 설정, 임시 썸네일과 호환성 판단용 축소 밝기 표본
  • 첫 설정에서 사용자가 직접 촬영한 Live Photo의 현재 기기 호환 정보
  • 변환된 HEIC 사진과 무음 H.264 paired MOV 또는 일반 MP4

WakeMotion 운영자는 위 원본, 프레임, 호환 정보, 편집 내용 또는 완성 파일을 WakeMotion 서버로 전송하거나 수집하지 않습니다. 이러한 앱 고유 데이터는 광고 요청에도 넣지 않습니다.

3. iPhone 맞춤 촬영

잠금 화면 호환성을 높이기 위해 사용자가 명시적으로 촬영 버튼을 누르면 카메라와 마이크 권한을 요청하고 Apple의 Live Photo 촬영 기능을 한 번 실행합니다. 마이크 권한은 Apple 촬영 파이프라인 구성에 필요하지만 WakeMotion이 만드는 최종 결과는 무음입니다.

촬영한 사진과 동영상 파일은 사진 보관함에 저장하지 않으며, 필요한 호환 정보를 추출한 직후 삭제합니다. 출력에 필요한 최소 profile만 Apple CryptoKit의 AES-GCM으로 암호화해 앱 전용 저장소에 보관하고, 암호 키는 다른 기기로 동기화되지 않는 ThisDeviceOnly Keychain에 저장합니다. iOS 버전·기기 모델·출력 규격이 달라지거나 사용자가 설정에서 삭제하면 profile과 키를 제거합니다.

호환 정보의 전체 내부 형식은 Apple이 공개하지 않았습니다. WakeMotion은 계정, 위치, 연락처, 얼굴, 사진 프레임, 오디오 또는 UDID를 의도적으로 profile에 넣지 않지만, 공개되지 않은 payload의 모든 필드 의미를 보증할 수는 없습니다. 같은 profile 일부는 사용자가 만드는 paired MOV 안에 포함되어 사진 보관함에 저장될 수 있습니다. WakeMotion은 이를 로그·분석·광고 요청·서버로 보내지 않습니다.

4. 사진 보관함과 권한

동영상 선택은 Apple PhotosPicker를 사용하므로 WakeMotion이 사용자의 전체 사진 목록을 열람하지 않습니다. 완성 결과를 저장할 때만 사진 추가 전용 권한을 요청합니다. 사용자가 iCloud Photos를 켠 경우 저장한 결과는 Apple 설정에 따라 iCloud로 동기화될 수 있으며, 이는 WakeMotion 서버 전송이 아닙니다.

5. 보관과 삭제

  • 선택 영상과 변환 임시 파일: 교체, 취소, 편집기 종료 또는 다음 앱 실행 때 삭제
  • 맞춤 촬영 HEIC/MOV: 추출 성공 또는 실패 직후 삭제
  • 암호화된 기기 profile: 사용자가 설정에서 삭제, 앱 삭제, 환경 불일치 또는 복호화 실패 때 삭제
  • 사진 보관함에 저장된 결과: 사용자가 Apple Photos에서 직접 관리

WakeMotion은 사용자의 원본 Photos 항목을 수정하거나 삭제하지 않습니다.

WakeMotion은 별도의 광고 데이터 사본이나 자체 사용자별 광고 profile을 보관하지 않습니다. Google SDK가 처리하는 광고·동의 데이터의 보관 기간, 처리 위치와 삭제는 Google의 정책과 사용자의 선택에 따르며 대한민국 밖에서 처리될 수 있습니다.

6. 광고와 동의 관리

WakeMotion 무료 버전은 Google Mobile Ads SDK와 Google User Messaging Platform SDK를 사용합니다. 광고 제공, 광고 빈도·성과 측정, 부정행위 방지, 동의 상태 처리와 SDK 개선을 위해 Google SDK는 IP 주소에서 파생될 수 있는 대략적 위치, 기기 또는 광고 관련 식별자, 광고 데이터, 앱 내 제품 상호 작용, 충돌·성능·기타 진단 데이터를 수집하거나 처리할 수 있습니다.

데이터 유형에 따라 타사 광고, 개발자의 마케팅, 분석 또는 앱 기능 제공 목적으로 사용되고 사용자나 기기에 연결되거나 추적에 사용될 수 있습니다. 실제 처리는 사용자의 지역, 동의 선택, 기기 설정과 Google 정책에 따라 달라질 수 있습니다. 자세한 내용은 Google 개인정보처리방침에서 확인할 수 있습니다.

적용 지역에서는 동의, 동의하지 않음 또는 옵션 관리 선택지가 표시될 수 있습니다. 개인정보 옵션을 다시 제공해야 하는 지역에서는 WakeMotion 설정에서 선택을 검토할 수 있습니다.

현재 앱은 Apple의 앱 추적 투명성 권한 요청을 자체적으로 표시하지 않습니다. 다만 포함된 Google 광고 SDK의 개인정보 manifest는 기기 ID가 추적 목적으로 사용될 수 있다고 선언하므로 WakeMotion은 App Store 개인정보 표시에 이를 보수적으로 공개합니다.

WakeMotion은 사용자 동영상·파일명·프레임·썸네일·편집 정보·iPhone 맞춤 profile·Live Photo metadata·완성 파일·진단 코드를 광고 요청에 넣지 않습니다. Firebase Analytics, Google Analytics, 별도 crash-reporting SDK, 광고 mediation, 자체 계정이나 backend도 사용하지 않습니다.

7. 지원 문의와 웹페이지

사용자가 이메일로 문의하면 답변을 위해 발신 이메일 주소와 문의 내용을 처리합니다. 원본 영상이나 완성 Live Photo를 보내지 마세요. 문의 기록은 지원과 분쟁 대응에 필요한 기간만 보관하고, 삭제 요청이나 보관 필요성 종료 시 제거합니다.

지원 이메일은 Google Gmail을, 이 페이지는 GitHub Pages를 사용합니다. 이메일 전송 또는 페이지 접속 과정에서 각 제공자가 자체 방침에 따라 기본 통신·접속 정보를 처리할 수 있습니다. WakeMotion은 이 웹페이지에 자체 분석 스크립트나 광고 쿠키를 넣지 않습니다. 자세한 내용은 Google 개인정보처리방침과 GitHub 개인정보취급방침을 확인해 주세요.

8. 사용자의 선택

  • iOS 설정에서 카메라·마이크·사진 권한 변경
  • WakeMotion 설정에서 개인정보 선택 메뉴가 표시될 때 광고 동의 옵션 검토
  • WakeMotion 설정에서 iPhone 맞춤 profile 교체 또는 삭제
  • 사진 보관함에서 완성 결과 삭제
  • 앱 삭제로 앱 전용 파일 제거
  • 지원 이메일을 통한 개인정보 문의 또는 지원 문의 기록 삭제 요청

Keychain 항목은 앱 재설치 뒤 남을 수 있으므로, 가능하면 앱을 삭제하기 전에 WakeMotion 설정에서 맞춤 profile을 먼저 삭제해 주세요.

9. 아동

WakeMotion은 어린이를 대상으로 설계하거나 마케팅하지 않으며 계정이나 생년월일을 수집하지 않습니다. 광고와 관련된 연령·동의 설정은 출시 국가의 요구사항과 App Store 연령 등급을 기준으로 검토합니다.

10. 보안

WakeMotion은 앱 sandbox, complete file protection, backup exclusion, atomic file write, AES-GCM과 ThisDeviceOnly Keychain을 사용해 앱 전용 임시 파일과 profile을 보호합니다. 어떤 방법도 절대적인 보안을 보장하지는 않습니다.

11. 변경과 문의

기능, SDK 또는 데이터 흐름이 바뀌면 이 방침과 시행일을 갱신합니다. 개인정보 관련 문의는 wakemotion.support@gmail.com으로 보내 주세요.
